Guia de mocks del dashboard
===========================

Fichero donde estan definidos los mocks:

  src/lib/data/mockDashboard.ts

Fichero donde se elige que mock se esta viendo en pantalla:

  src/routes/+page.svelte

Para cambiar el caso que quieres probar, cambia el import de +page.svelte para que
mockDriverRows y mockSessionState apunten al mock que quieras ver.


Caso por defecto: carrera
-------------------------

Import:

  import {
    mockDriverRows,
    mockSessionState
  } from '../lib/data/mockDashboard';

Tambien puedes usar explicitamente:

  import {
    mockRaceDriverRows as mockDriverRows,
    mockRaceSessionState as mockSessionState
  } from '../lib/data/mockDashboard';

Que se espera ver:

  - Header en modo Race.
  - Card de vueltas visible.
  - Tabla completa con columna LAPS.
  - Sin zona de eliminacion.
  - Si el TrackStatus es amarillo, VSC, SC o rojo, la tabla debe parpadear con
    el color correspondiente.


Caso base: qualy
----------------

Import:

  import {
    mockQualifyingDriverRows as mockDriverRows,
    mockQualifyingSessionState as mockSessionState
  } from '../lib/data/mockDashboard';

Que se espera ver:

  - Header en modo Qualifying.
  - Debe aparecer Q1, Q2 o Q3 si qualifyingPartLabel esta definido.
  - No debe aparecer la card de LAPS del header.
  - La columna LAPS de la tabla no debe mostrarse.
  - Debe aparecer la linea "Elimination zone" antes del primer piloto en zona
    de eliminacion, si eliminationZoneStartsAt tiene valor.
  - Los pilotos eliminados deben aparecer mas apagados.

Que se espera ver:

Notas importantes
-----------------

  - Race muestra LAPS; Qualy y Practice no deberian mostrar LAPS.
  - El borde amarillo de cutoff solo debe verse cuando la sesion esta en directo.
  - La linea de eliminacion no sale de los datos raw directamente: normalmente
    la calcula el backend segun la parte de qualy:
      Q1 -> empieza en posicion 16
      Q2 -> empieza en posicion 11
      Q3 -> null
  - Los mocks sirven para probar la visualizacion antes de conectar el backend
    real.
